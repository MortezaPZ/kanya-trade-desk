# راهنمای نصب و استفادهٔ فارسی

این راهنما برای نسخهٔ ویندوزی Kanya Trade Desk است. برنامه قیمت و نمادها را از ترمینال محلی MetaTrader 5 می‌خواند؛ رمز بروکر را ذخیره نمی‌کند و هیچ سفارش خرید یا فروشی نمی‌فرستد. برنامه کمکی برای بررسی بازار است و نتیجه یا سود را تضمین نمی‌کند.

## نصب نسخهٔ ویندوزی

1. بستهٔ ZIP برنامه را در رایانه ذخیره و استخراج کنید.
2. MetaTrader 5 را باز کنید و به حساب دلخواه خود وارد شوید.
3. `KanyaTradeDesk.exe` را اجرا کنید؛ صفحهٔ برنامه در مرورگر و روی همان رایانه باز می‌شود.
4. اگر صفحهٔ مرورگر بسته شد، در پنجرهٔ برنامه گزینهٔ «بازکردن صفحه» را بزنید.
5. برای پایان کار، پنجرهٔ برنامه را ببندید.

برای اجرای نسخهٔ آماده نیازی به نصب Python یا واردکردن دستور در ترمینال نیست. صفحهٔ برنامه فقط روی همین رایانه در دسترس است. تنظیمات خصوصی در `%APPDATA%\KanyaTradeDesk\.env` و سابقهٔ محلی در همان پوشه نگه‌داری می‌شوند.

## تنظیم اختیاری تحلیل هوش مصنوعی

تحلیل هوش مصنوعی به دسترسی جداگانهٔ API نیاز دارد؛ اشتراک معمولی چت به‌تنهایی کافی نیست و مصرف API ممکن است هزینه داشته باشد. پیش از استفاده، نشانی API، شناسهٔ مدل، پروتکل و روش احراز هویت را از مستندات رسمی ارائه‌دهنده بگیرید.

مقادیر را در فایل محلی `.env` تنظیم کنید:

```text
LLM_PROTOCOL=chat_completions
LLM_BASE_URL=https://provider.example/v1
LLM_API_KEY=<کلید-خصوصی-محلی>
LLM_MODEL=<شناسه-مدل>
LLM_AUTH_HEADER=Authorization
LLM_AUTH_PREFIX=Bearer
LLM_VERSION_HEADER=
LLM_API_VERSION=
```

برای پروتکل Messages، مقدار `LLM_PROTOCOL=messages_v1` را انتخاب کنید و نام هدرها و نسخه را دقیقاً طبق مستندات همان API بنویسید. اگر چند ترمینال نصب است، در صورت نیاز `MT5_PATH` را هم در `.env` تنظیم کنید.

درخواست API فقط وقتی فرستاده می‌شود که دکمهٔ «مشاوره قبل از ورود» را بزنید. درخواست شامل نماد، قیمت جاری، خلاصهٔ شاخص‌های فنی و حداکثر ۴۰ کندل بسته‌شده از هر تایم‌فریم است؛ موجودی، اکوئیتی، موقعیت‌های باز، حجم پیشنهادی و یادداشت ورود ارسال نمی‌شوند. بدون تنظیم معتبر API، برنامه صریحاً اعلام می‌کند که تحلیل هوش مصنوعی در دسترس نیست.

کلید API را داخل Git، فایل ZIP عمومی، صفحهٔ مرورگر یا پیام‌رسان قرار ندهید. آن را فقط در فایل `.env` محلی ذخیره کنید و سقف مصرف را در حساب ارائه‌دهنده تنظیم کنید.

## استفادهٔ روزانه

1. MetaTrader 5 را باز کنید؛ ابزار از ترمینال قیمت و نمادها را می‌خواند.
2. `KanyaTradeDesk.exe` را اجرا کنید.
3. واچ‌لیست را مرور و نماد دلخواه را انتخاب کنید.
4. برای دریافت تحلیل، «مشاوره قبل از ورود» را بزنید. این ابزار سفارشی ثبت نمی‌کند.
5. پس از معامله، در صورت نیاز «مرور بعد از معامله» را برای دیدن نتیجهٔ آخرین معاملهٔ همان نماد انتخاب کنید.

اگر ترمینال بسته باشد، برنامه دادهٔ ساختگی نشان نمی‌دهد. در آن حالت ابتدا اتصال MetaTrader 5 را برقرار کنید و دوباره تلاش کنید.
